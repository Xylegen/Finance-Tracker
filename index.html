Home Ledger

Home Ledger is a private, single-user personal finance tracker. It runs only on its owner's own computer and is not offered to the public.

What it does

Home Ledger reads the transaction alert emails that banks and card issuers send to its owner's Gmail account, and turns them into a personal record of spending. It uses read-only access to Gmail for this purpose alone.

How it uses Google data

The app requests the Gmail read-only permission. It reads only transaction alert emails from financial institutions. It cannot send, change or delete email. Everything it reads is stored on the owner's computer and is not shared with anyone.
